# Smart Campus Attendance and Performance Analytics System

## Project Description

The Smart Campus Attendance and Performance Analytical System is a database-based project designed to manage and analyze student attendance and academic performance efficiently. The system provides a centralized platform for storing and managing student information, attendance records, and academic performance data.

The main purpose of this system is to help educational institutions organize student records and generate meaningful insights from attendance and performance data. By maintaining accurate records, the system can support better monitoring of student progress and help identify patterns related to attendance and academic performance.

## Key Features

- Student information management
- Attendance record management
- Academic performance record management
- Storage and retrieval of student data
- SQL queries for data analysis and reporting
- Analysis of student attendance and academic performance
- Organized and centralized database management

## Technologies Used

## Database Concepts Used
- Normalized Schema
- Database and table creation
- Primary and foreign keys
- Relationships between tables
- Data insertion, updating, and deletion
- SQL queries
- Aggregate functions
- Joins and subqueries
- Stored Procedure use for GPA Calculation
- Triggers for attendance alert
- Views for performance summaries
- Indexing on unique data
- Transaction for grade submissions 

## Purpose of the Project

The purpose of this project is to demonstrate the practical implementation of Database Management System concepts in a real-world academic environment. It focuses on efficient data management and analysis to support better decision-making regarding student attendance and academic performance.
